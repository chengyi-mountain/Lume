> **Your First Step into Anything.**
> 输入你想学的科目，自动生成一份「听得懂、学得会、不放弃」的学习目标和路径。
> 全程大白话，零基础也能上手；卡住了右下角直接问，像有个朋友在旁边陪你学。

🔗 **在线体验**：https://chengyi-mountain.github.io/Lume/

## 🚀 快速开始

### 方式一：本地直接打开

下载 `index.html`，双击用浏览器打开即可，无需联网、无需安装任何东西。

### 方式二：部署到 GitHub Pages（推荐，免费）

1. 在 GitHub 新建仓库（命名 `Lume`），把 `index.html` 上传到仓库根目录；
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`；
3. 保存后等待 1–2 分钟，访问 `https://<你的用户名>.github.io/Lume/` 即可。

### 替换仓库地址（仅 fork 自建时需要）

本仓库的「提 issue / 请求收录科目」链接已指向 `chengyi-mountain/Lume`。如果你 fork 后自建部署，需要改成你自己的仓库：打开 `index.html`，搜索 `chengyi-mountain/Lume`，替换成 `用户名/仓库名`；也可以在 `index.html` 的 `</body>` 前显式声明，优先级更高：

```html
<script>
  window.LUME_REPO = "你的用户名/Lume";
</script>
```

## 🤖 接入 AI 智能体（可选）

不配置也完全可用，助手会自动走「内置知识库」通道，离线即答。

### 方式一：页面设置弹窗

打开网站 → 点右下角 💬 → 通道下拉选「AI 智能体」→ 按提示填入接口信息。

> 默认建议用额度 / 限速的 Key，避免烧钱。

### 方式二：写进代码（适合自建部署）

在 `index.html` 的 `</body>` 前加一段：

```html
<script>
  window.LUME_STUDIO_CONFIG = {
    api: "https://你的接口地址",
    model: "模型名",
    format: "openai",                // 是否为 OpenAI 兼容格式
    headers: { Authorization: "Bearer 你的Key" }
  };
</script>
```

支持的供应商（改 `api` / `model` / `headers` 即可）：

| 供应商 | api 示例 | format |
|---|---|---|
| 混元（腾讯云） | `https://hunyuan.tencentcloudapi.com/v1/chat/completions` | `openai` |
| DeepSeek | `https://api.deepseek.com/v1/chat/completions` | `openai` |
| OpenAI 兼容 | 任意兼容 `/v1/chat/completions` 的地址 | `openai` |
| 自定义接口 | 你的服务端地址 | 不填，提供 `bodyBuilder` 自行组装请求体 |

更灵活的自定义请求体：

```html
<script>
  window.LUME_STUDIO_CONFIG = {
    api: "https://你的接口地址",
    bodyBuilder: (name, prompt, cfg) => JSON.stringify({
      model: cfg.model,
      system: "你是学习助手",
      input: prompt
    })
  };
</script>
```

> ⚠️ 安全提醒：自建部署时不要把 Key 硬编码进公开仓库；如果一定要提交，请使用受限 / 低额度 Key，或用环境变量在构建时注入。**Key 只存在用户本地浏览器，本项目不会上传、不会收集。**

## 📚 贡献新科目

科目计划是纯数据，加一个科目只要往 `index.html` 的 `SUBJECTS` 数组里塞一条：

```javascript
{
  id: "guitar", icon: "🎸", name: "吉他", cat: "音乐与艺术", hot: false,
  intro: "一句话说清它是什么、学了能干嘛",
  goals: {
    beginner: ["能弹唱 3 首完整歌曲", "..."],
    advanced: ["能即兴伴奏、扒谱", "..."]
  },
  phases: {
    beginner: [
      { title: "阶段名", meta:{ time:"1-2 周", out:"阶段产出" },
        quote: "一句大白话解释这阶段在干啥",
        items: ["具体知识点 1", "具体知识点 2", "..."] }
    ],
    advanced: [ /* 同上结构 */ ]
  },
  tips: { beginner: ["避坑 1", "..."], advanced: ["避坑 1", "..."] },
  resources: [ { t: "资源名", d: "一句话说明" }, ... ]
}
```

**字段约定**

- `id` 全小写英文，全局唯一；`icon` 用 emoji；
- `cat` 建议从现有方向中选：编程技术 / AI与智能 / 职业技能 / 语言学习 / 学科与考试 / 兴趣生活 / 办公与效率 / 音乐与艺术 / 数据与 AI / 理财与生活 / 个人成长 / 设计与创作；
- 每个阶段 **必须** 有 `quote`（大白话解释），这是本项目「不劝退」的核心；
- 未内置科目会走本地规则引擎，但收录到 `SUBJECTS` 后能提供质量更高的专属方案。

你也可以在网站上：输入科目 → 等本地方案生成 → 点「复制为 JSON」→ 去 GitHub 提 PR，作者审核后即可合并。

扩充内置知识库同理：在 `KB` 数组里加 `{q:"问题", a:"回答"}` 即可。

### 资源推荐必须遵守的链接规则（白名单卡口）

资源卡片分两种，只有**通过检测**的才会渲染成可点击链接：

| 写法 | 渲染结果 | 适用 |
|---|---|---|
| `{ t:"菜鸟教程 Python3", d:"中文免费，语法速查首选", u:"https://www.runoob.com/python3/python3-tutorial.html" }` | 可点，带 ↗，一步直达 | 官网文档、权威免费教程、官方机构、免费平台的**平台内搜索直链** |
| `{ t:"《SQL 必知必会》", d:"薄薄一本，入门经典", h:"书籍 · 微信读书或图书馆找" }` | **不可点击**，底部显示获取方式提示 | 书籍、APP、付费课、需外网才能访问的站点 |

硬性要求：

1. `u` 的域名必须命中 `tools/link-policy.json` 里的 `whitelist`，否则测试失败；
2. 命中 `blacklist`（电商 / 付费课 / 聚合搜索页，如 bing、baidu、jd、taobao、geekbang）一律不给链接，黑名单优先；
3. **每个科目至少要有 1 条合规直达链接**，缺了直接判失败；
4. 书籍只写书名 + 获取方式，不要引到购书页。

自检命令（建议改完资源就跑一遍）：

```bash
python tools/link-audit.py         # 静态规则校验
python tools/link-audit.py --net   # 附带 90 条链接的线上存活检测（404/410 才算死链）
```

## 🎯 学习单元（Unit）：从「给一份计划」到「陪你走完计划」

整套计划适合「下定决心」的那一天，不适合「今天有点累」的晚上。所以科目被拆成了**可执行单元**：一个单元 = 一次 30–60 分钟能做完的事，且必须留下一个**能看见的产出**。

一个单元长这样（数据在 `index.html` 的 `window.UNITS` 里）：

```javascript
"python": [
  { id:"u1", t:"装上环境，跑通第一个程序",
    goal:"能在自己电脑上跑通一个 .py 文件，从此不怕黑框框",
    mins:40,
    steps:[ "装 Python 3.11+（Windows 安装时勾上 Add python.exe to PATH）",
            "新建 hello.py，写一行 print(\"你好，Lume\")",
            "打开终端，输入 python hello.py 看结果",
            "把引号里的字改成你的名字，再跑一次" ],
    proof:"终端能显示 python --version 的版本号，且 hello.py 输出的是你自己写的内容",
    res:[0,6] }        // 下标指向该科目 resources 里的条目，自动继承白名单校验
]
```

四个字段的分工：`steps` 是今天要做的事，`proof` 是「怎样算学会」（验收判据），`res` 是这一单元只留一两个资源，`mins` 是预计耗时。

**四态状态机**：`未开始` → 勾掉一步变 `进行中` → 全勾完变 `待验收` → 点「我做到了」变 `已掌握`。只有验收通过才算学会，光勾完不算。

**断点续做**：首页顶部会出现「☀️ 今日任务」卡，直接告诉你接着上次哪一步继续，不用每次重新翻计划。

**存储键**：`le_unit_<科目id>` 存单元进度，`le_active` 存当前指针；两者都已被「导出 / 导入 / 重置进度」一并覆盖，也随浏览器本地保存，不上传。

当前已单元化的科目：`python`、`frontend`、`excel`、`english`、`ai-prompt`、`time-mgmt`（共 38 个单元）；其余科目仍走原来的整体路径，并在科目页给出提示。新增单元按上面的字段约定往 `UNITS` 里加即可。

## 🕘 记住上次：搜索记忆与断点恢复

打开网页不用重新找路，浏览器本地会记住三件事：

| 记什么 | 存哪 | 什么时候用上 |
|---|---|---|
| 最近搜过的词（最多 6 条，新的在前、重复的会提到最前） | `le_q_hist` | 搜索框下方显示「🕘 最近搜过」胶囊，点一下直接重搜；一行右侧有「清空」 |
| 上次停在哪个单元 | `le_active` | 打开网页直接回到那个单元，勾选状态原样还在 |
| 上次看的科目 | `le_last_subject` | 只是看过科目、没进单元时，回到那个科目页 |

两条刻意的克制：

1. **只恢复 14 天内的现场**，更久远的回到首页，避免「一打开就落在某个早就过时的科目页」；
2. **你点过「← 返回首页」就以首页为准**（时间戳存 `le_home_at`），只有之后又继续学过，才会恢复上次位置。

搜索框也会回填：有上次科目就填科目名，否则填最近搜过的第一个词（只回填、不自动搜，留给你改）。

以上这些键都在「导出 / 导入 / 重置进度」的覆盖范围内，且只存本地浏览器，不上传。
